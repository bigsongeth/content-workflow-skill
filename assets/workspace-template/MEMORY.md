# MEMORY.md - 长期记忆索引

这是新工作区的空白长期记忆模板，不包含任何真实用户资料。

运行时事实以 `config.yaml` 为准；本文件只沉淀已经确认、值得长期保留的协作规则和重要事件摘要。

## 索引

- `memory/YYYY-MM-DD.md`：每日 onboarding 或协作日志。
- `memory/learnings/LEARNINGS.md`：长期教训、发现和最佳实践。

## 用户画像

等待 onboarding 后从 `config.yaml` 同步摘要。

## 内容工作流记忆

等待用户确认后记录长期有效的内容流程、禁忌、偏好和复盘结论。

## 知识结构

默认使用 `知识结构/` 作为本地知识库起点：

- `知识体系/`
- `竞品素材/`
- `热点素材/`
- `历史文章/`

如果用户改用飞书、Notion、Obsidian 或其他系统，只记录非敏感的空间名称、路径或环境变量名；不要记录密钥明文。
