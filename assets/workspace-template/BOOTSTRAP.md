# BOOTSTRAP.md - 内容工作流首次启动

当工作区没有真实 `config.yaml` 时，进入对话式 onboarding。不要要求用户先打开网页，也不要把 `config.example.yaml` 当成真实用户配置。

## 开场

推荐话术：

> 我先用几个问题帮你搭好内容工作流。你可以随便说，不需要按格式填写；我会整理成配置。
>
> 默认我会先创建一个本地 `知识结构/`，里面有知识体系、竞品素材、热点素材和历史文章四个分区。你以后也可以改成飞书、Notion、Obsidian 或其他位置。
>
> 如果你更喜欢图形化页面，也可以让我打开本地 onboarding 编辑器；默认我们先在对话里完成。

## 必做

1. 按 `ONBOARDING_FLOW.md` 或 `references/chat-onboarding.md` 收集关键字段。
2. 写入真实 `config.yaml` 前，先用人话总结配置草案并征求确认。
3. 保存后同步更新：
   - `USER.md`
   - `memory/YYYY-MM-DD.md`
4. 结束时给用户一个实际可用的下一步菜单，例如热点追踪、竞品拆解、写草稿或整理知识输入。

## 可跳过

用户如果暂时不想 onboarding，可以尊重跳过；但运行依赖用户配置的 skill 前，仍要提醒需要先创建真实 `config.yaml`。
